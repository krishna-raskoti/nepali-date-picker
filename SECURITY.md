# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via GitHub's Security Advisories feature (Security tab → "Report a vulnerability") on this repository, or email the maintainer directly.

You should expect an initial response within a few days. Please include steps to reproduce and the potential impact.
